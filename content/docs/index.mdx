**Website Belajar Golang** menyediakan jalur belajar bertahap untuk berbagai **segmen pembelajaran**. Setiap segmen berdiri sendiri dan dapat dipelajari sesuai kebutuhanmu. Segmen saat ini adalah **Backend**; segmen lain akan menyusul.

<Callout title="Segmen = tab di sidebar" type="info">
Setiap segmen tampil sebagai **tab** di bagian atas sidebar. Klik tab untuk berpindah segmen tanpa kehilangan konteks. Segmen baru cukup ditambahkan sebagai folder baru.
</Callout>

## Segmen Backend

Segmen **Backend** terdiri dari **5 fase** dan **16 pertemuan**:

| Fase | Fokus | Pertemuan |
| --- | --- | --- |
| Fase 1 | Fondasi Golang & Sintaks Dasar | 1–4 |
| Fase 2 | Concurrency & Unit Testing | 5–6 |
| Fase 3 | Web API & Integrasi Database | 7–10 |
| Fase 4 | Otentikasi, Arsitektur & Otorisasi | 11–13 |
| Fase 5 | Fitur API Lanjutan, Docker & Deployment | 14–16 |

Mulai dari [Kurikulum Backend](./backend), lalu ikuti setiap pertemuan secara berurutan.
