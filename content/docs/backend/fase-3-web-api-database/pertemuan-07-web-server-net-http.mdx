Sebelum memakai framework, penting memahami cara kerja HTTP server di Go. Paket `net/http` adalah fondasinya, dan framework populer seperti Gin dibangun di atas konsep yang sama.

## Tujuan Pembelajaran

- Memahami arsitektur client-server pada aplikasi web.
- Membuat HTTP server dengan paket `net/http`.
- Memahami `http.Handler`, `http.ResponseWriter`, dan `http.Request`.
- Mengelola routing dengan `http.ServeMux`.

## 1. Arsitektur Client-Server

```text
Client (browser/Postman)  ──HTTP Request──►  Server (Go)
      ▲                                          │
      └────────── HTTP Response ─────────────────┘
```

- **Client** mengirim request berisi method, path, header, dan body.
- **Server** memproses lalu mengembalikan response berisi status code, header, dan body.
- Komunikasi bersifat **stateless**: setiap request berdiri sendiri (kecuali kita menyimpan state sendiri, mis. sesi/JWT).

## 2. Server Pertama

```go title="main.go"
package main

import (
	"fmt"
	"net/http"
)

func main() {
	http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintln(w, "Halo, Web!")
	})

	fmt.Println("server jalan di :8080")
	http.ListenAndServe(":8080", nil)
}
```

Jalankan lalu uji:

```bash title="Terminal"
go run main.go
curl http://localhost:8080/
```

## 3. Handler, ResponseWriter, dan Request

Handler adalah fungsi dengan tanda tangan `func(w http.ResponseWriter, r *http.Request)`. Tipe `http.Handler` didefinisikan sebagai interface dengan satu method `ServeHTTP`:

```go title="handler.go"
type Handler interface {
	ServeHTTP(w http.ResponseWriter, r *http.Request)
}
```

Mengirim response JSON:

```go title="json_handler.go"
func healthHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(http.StatusOK)
	w.Write([]byte(`{"status":"ok"}`))
}
```

Membaca request:

```go title="read_request.go"
func echoHandler(w http.ResponseWriter, r *http.Request) {
	method := r.Method
	path := r.URL.Path
	query := r.URL.Query().Get("nama")
	ua := r.Header.Get("User-Agent")

	fmt.Fprintf(w, "%s %s | nama=%s | ua=%s", method, path, query, ua)
}
```

## 4. Routing dengan ServeMux

`http.ServeMux` memetakan path ke handler. Sejak Go 1.22, ia mendukung **method** dan **path parameter**.

```go title="mux.go"
func main() {
	mux := http.NewServeMux()

	mux.HandleFunc("GET /users", listUsers)
	mux.HandleFunc("POST /users", createUser)
	mux.HandleFunc("GET /users/{id}", getUser) // path parameter

	http.ListenAndServe(":8080", mux)
}

func getUser(w http.ResponseWriter, r *http.Request) {
	id := r.PathValue("id") // ambil {id}
	fmt.Fprintln(w, "user id:", id)
}
```

<Callout title="Kenapa belajar net/http dulu?" type="info">
Semua framework Go tetap memakai `http.ResponseWriter` dan `http.Request`. Memahami keduanya membuatmu tidak buta saat debugging atau menulis middleware.
</Callout>

## 5. Method Handler

Bungkus handler agar bisa memenuhi interface `http.Handler`:

```go title="middleware.go"
type Middleware func(http.Handler) http.Handler

func Logging(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Println(r.Method, r.URL.Path)
		next.ServeHTTP(w, r)
	})
}
```
