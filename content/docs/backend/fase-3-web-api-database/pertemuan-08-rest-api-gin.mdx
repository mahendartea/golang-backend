Gin adalah framework web Go yang cepat dan ringkas. Pertemuan ini mengubah server `net/http` manual menjadi REST API yang terstruktur dengan Gin.

## Tujuan Pembelajaran

- Menyiapkan Gin Engine dengan `gin.Default()`.
- Menangani routing HTTP (GET, POST, PUT, DELETE).
- Mengambil path parameter, query parameter, dan JSON body.
- Memvalidasi request dengan binding tag.

## 1. Setup Gin

```bash title="Terminal"
go get github.com/gin-gonic/gin
```

```go title="main.go"
package main

import "github.com/gin-gonic/gin"

func main() {
	r := gin.Default() // logger + recovery middleware

	r.GET("/health", func(c *gin.Context) {
		c.JSON(200, gin.H{"status": "ok"})
	})

	r.Run(":8080") // default :8080
}
```

<Callout title="gin.Default vs gin.New" type="info">
`gin.Default()` menyertakan middleware **Logger** dan **Recovery** (mencegah panic mematikan server). `gin.New()` membuat engine kosong tanpa middleware.
</Callout>

## 2. Routing REST

```go title="routes.go"
r.GET("/users", listUsers)       // ambil semua
r.GET("/users/:id", getUser)     // detail
r.POST("/users", createUser)     // buat
r.PUT("/users/:id", updateUser)  // perbarui
r.DELETE("/users/:id", deleteUser)
```

Gunakan **route group** untuk merapikan versi API:

```go title="group.go"
v1 := r.Group("/api/v1")
{
	v1.GET("/users", listUsers)
	v1.POST("/users", createUser)
}
```

## 3. Path & Query Parameter

```go title="params.go"
func getUser(c *gin.Context) {
	id := c.Param("id") // dari /users/:id
	c.JSON(200, gin.H{"id": id})
}

func listUsers(c *gin.Context) {
	page := c.DefaultQuery("page", "1") // query ?page=2
	search := c.Query("search")         // kosong jika tidak ada
	c.JSON(200, gin.H{"page": page, "search": search})
}
```

## 4. JSON Request Body

Definisikan struct request lalu ikat dengan `c.ShouldBindJSON`.

```go title="create_user.go"
type CreateUserRequest struct {
	Name     string `json:"name" binding:"required,min=3"`
	Email    string `json:"email" binding:"required,email"`
	Password string `json:"password" binding:"required,min=8"`
}

func createUser(c *gin.Context) {
	var req CreateUserRequest

	if err := c.ShouldBindJSON(&req); err != nil {
		c.JSON(400, gin.H{"error": err.Error()})
		return
	}

	c.JSON(201, gin.H{
		"message": "user dibuat",
		"data":    req,
	})
}
```

Tag `binding` memakai **go-playground/validator** yang sudah terintegrasi dengan Gin. Beberapa tag berguna:

| Tag | Arti |
| --- | --- |
| `required` | Wajib diisi. |
| `email` | Harus format email. |
| `min=8` | Panjang minimal 8. |
| `max=100` | Panjang maksimal 100. |
| `oneof=admin user` | Nilai harus salah satu dari daftar. |
| `gte=0` | Lebih besar atau sama dengan 0. |

## 5. Response Konsisten

Buat helper agar format response seragam:

```go title="response.go"
func success(c *gin.Context, data any) {
	c.JSON(200, gin.H{"success": true, "data": data})
}

func fail(c *gin.Context, code int, msg string) {
	c.JSON(code, gin.H{"success": false, "error": msg})
}
```

## Latihan

1. Buat endpoint CRUD `/api/v1/books` (GET, POST, PUT, DELETE).
2. Gunakan struct request dengan validasi `required`, `min`, dan `email`.
3. Tambahkan query parameter `page` dan `limit` pada endpoint list.
4. Kembalikan status code yang tepat: `201` saat create, `400` saat validasi gagal, `404` saat data tidak ada.
