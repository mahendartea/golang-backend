Fase ini adalah inti pengembangan backend. Kamu akan membangun **HTTP server** dari paket standar, kemudian beralih ke **framework Gin**, lalu menghubungkan aplikasi ke **PostgreSQL** melalui **GORM** — termasuk relasi dan transaksi.

## Target Kompetensi

- Mampu membangun REST API lengkap dengan validasi request.
- Mampu memodelkan dan mengelola data di PostgreSQL dengan GORM.
