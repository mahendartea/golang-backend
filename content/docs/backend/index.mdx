Selamat datang di **Segmen Backend**. Kurikulum ini disusun bertahap dalam **16 pertemuan** yang terbagi menjadi **5 fase**: dari sintaks dasar bahasa Go, concurrency, pembangunan REST API, integrasi database, otentikasi, arsitektur bersih, hingga containerization dan deployment ke infrastruktur modern.

<Callout title="Cara menggunakan path ini" type="info">
Setiap pertemuan berdiri sendiri namun saling bergantung. Selesaikan secara berurutan, kerjakan bagian **Latihan**, lalu verifikasi dengan **checklist** di akhir halaman sebelum lanjut ke pertemuan berikutnya.
</Callout>

## Prasyarat

- Dasar pemrograman (variabel, fungsi, perulangan) dari bahasa apa pun.
- Komputer dengan minimal 4 GB RAM dan terminal.
- Koneksi internet untuk mengunduh Go SDK dan dependency.
- Akun gratis opsional: [NeonDB](https://neon.tech), [ImageKit](https://imagekit.io), [Docker Hub](https://hub.docker.com).

## Hasil Akhir

Di akhir kurikulum kamu akan memiliki **satu proyek REST API produksi** yang:

- Memakai struktur **Clean Architecture** dengan layer yang terisolasi.
- Terhubung ke **PostgreSQL** melalui GORM beserta relasi dan transaksi.
- Mengamankan endpoint dengan **JWT + RBAC** dan **CORS**.
- Diuji dengan **unit test** dan **mock**.
- Terbungkus **Docker image** kecil (multi-stage build).
- Ter-deploy ke **Kubernetes** (atau Render/Railway sebagai alternatif).
