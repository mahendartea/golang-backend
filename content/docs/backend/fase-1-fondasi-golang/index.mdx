Fase ini membangun **fondasi bahasa Go**. Tanpa menguasai sintaks, struct, interface, dan pola error handling, kamu akan kesulitan memahami layer backend di fase berikutnya. Go sengaja dibuat sederhana dan eksplisit — filosofi ini akan terasa sepanjang kurikulum.

## Target Kompetensi

- Mampu menyiapkan environment Go dan menjalankan program.
- Mampu menulis tipe data, struct, dan fungsi yang idiomatik.
- Memahami interface dan pola error handling khas Go.
